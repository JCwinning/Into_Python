1 Introduction to Plotly

Plotly’s Python graphing library makes it easy to create interactive, publication-quality graphs. This document demonstrates how to create various plots, including line plots, scatter plots, bar charts, box plots, histograms, and more.

Code 
library(reticulate)
py_require(c('plotly','pandas','seaborn','psutil','requests'))
Code 
import plotly
print(plotly.__version__)
6.5.2

2 Scatter Plot

A scatter plot is used to visualize the relationship between two continuous variables.

Code 
fig = px.scatter(tips, x="tip", y="total_bill")
fig.show()

2.1 Color by Group

You can color the points based on a categorical variable to see how the relationship varies across different groups.

Code 
fig = px.scatter(tips, x="tip", y="total_bill", color="sex")
fig.show()

2.2 Size by Group

The size of the points can be mapped to a variable to add another dimension to the plot.

Code 
fig = px.scatter(tips, x="tip", y="total_bill", size="size")
fig.show()

3 Line Plot

A line plot is suitable for showing the trend of a variable over time.

import plotly.express as px

You can also add markers to the line plot to highlight the data points.

import plotly.express as px
fig = px.line(dowjones, x="Date", y="Price", markers=True)

3.2 Color by Group

You can plot multiple lines on the same plot to compare different groups.

4 Histogram

A histogram visualizes the distribution of a single continuous variable.

fig = px.box(tips, y="total_bill")

import plotly.graph_objects as go
import pandas as pd

# 1. Nodes Data
labels = [
    "Search<br>$63.1B", "YouTube<br>$11.4B", "AdMob<br>$7.8B", # 0, 1, 2
    "Google Play<br>$13.6B", "Google Cloud<br>$17.7B", "Other<br>$0.3B", # 3, 4, 5
    "Ad Revenue<br>$82.3B", # 6
    "Revenue<br>$113.8B", # 7
    "Gross profit<br>$68.1B", "Cost of revenues<br>($45.8B)", # 8, 9
    "Operating profit<br>$35.9B", "Operating expenses<br>($32.1B)", # 10, 11
    "Net profit<br>$34.5B", "Tax<br>($4.7B)", # 12, 13
    "Other CoR<br>($29.2B)", "TAC<br>($16.6B)", # 14, 15
    "R&D<br>($18.6B)", "S&M<br>($8.2B)", "G&A<br>($5.3B)", # 16, 17, 18
    "Other<br>$3.2B" # 19
]

# 2. Manual Positions (x: 0 is left, 1 is right | y: 0 is top, 1 is bottom)
x_pos = [
    0.001, 0.001, 0.001, # Search, YT, AdMob
    0.001, 0.001, 0.001, # Play, Cloud, Other
    0.20, # Ad Revenue
    0.35, # Revenue
    0.55, 0.55, # Gross, Cost
    0.75, 0.75, # Op Profit, Op Expenses
    0.99, 0.99, # Net, Tax
    0.85, 0.85, # Other CoR, TAC
    0.99, 0.99, 0.99, # R&D, S&M, G&A
    0.75 # Other Inc
]

y_pos = [
    0.05, 0.20, 0.35, # Search, YT, AdMob (Top-Left)
    0.55, 0.70, 0.85, # Play, Cloud, Other (Bottom-Left)
    0.20, # Ad Rev (Merges top three)
    0.45, # Revenue (Center)
    0.30, 0.80, # Gross (Top), Cost (Bottom)
    0.25, 0.65, # Op Prof (Top), Op Ex (Mid)
    0.20, 0.40, # Net (Top), Tax (Below Net)
    0.90, 0.80, # Other CoR (Bottom), TAC (Above it)
    0.55, 0.65, 0.75, # R&D, S&M, G&A
    0.10 # Other Inc
]

# 3. Node Colors
node_colors = [
    "#4285F4", "#4285F4", "#4285F4", # Sources Blue
    "#FBBC05", "#FBBC05", "#FBBC05", # Play/Cloud/Other Yellow
    "#4285F4", # Ad Rev Blue
    "#4285F4", # Revenue Blue
    "#34A853", "#EA4335", # Gross Green, Cost Red
    "#34A853", "#EA4335", # Op Prof Green, Op Ex Red
    "#34A853", "#EA4335", # Net Green, Tax Red
    "#EA4335", "#EA4335", # Other CoR, TAC Red
    "#EA4335", "#EA4335", "#EA4335", # R&D... Red
    "#34A853" # Other Inc Green
]

# 4. Links Data Frame
data = {
    'source': [0, 1, 2, 6, 3, 4, 5, 7, 7, 9, 9, 8, 8, 11, 11, 11, 10, 10, 19],
    'target': [6, 6, 6, 7, 7, 7, 7, 9, 8, 15, 14, 11, 10, 16, 17, 18, 12, 13, 12],
    'value': [63.1, 11.4, 7.8, 82.3, 13.6, 17.7, 0.3, 45.8, 68.1, 16.6, 29.2, 32.1, 35.9, 18.6, 8.2, 5.3, 31.2, 4.7, 3.2],
    'color': [
        "rgba(66, 133, 244, 0.4)", "rgba(66, 133, 244, 0.4)", "rgba(66, 133, 244, 0.4)", # -> AdRev
        "rgba(66, 133, 244, 0.6)", # AdRev -> Rev
        "rgba(251, 188, 5, 0.4)", "rgba(251, 188, 5, 0.4)", "rgba(251, 188, 5, 0.4)", # -> Rev
        "rgba(234, 67, 53, 0.4)", "rgba(52, 168, 83, 0.4)", # Rev -> Cost / Gross
        "rgba(234, 67, 53, 0.4)", "rgba(234, 67, 53, 0.4)", # Cost -> TAC / Other
        "rgba(234, 67, 53, 0.4)", "rgba(52, 168, 83, 0.4)", # Gross -> OpEx / OpProfit
        "rgba(234, 67, 53, 0.4)", "rgba(234, 67, 53, 0.4)", "rgba(234, 67, 53, 0.4)", # OpEx -> R&D...
        "rgba(52, 168, 83, 0.4)", "rgba(234, 67, 53, 0.4)", # OpProfit -> Net / Tax
        "rgba(52, 168, 83, 0.4)" # OtherInc -> Net
    ]
}

df = pd.DataFrame(data)

# 5. Create Figure
fig = go.Figure(data=[go.Sankey(
    arrangement = "fixed",
    node = dict(
      pad = 15,
      thickness = 20,
      line = dict(color = "black", width = 0.5),
      label = labels,
      color = node_colors,
      x = x_pos,
      y = y_pos
    ),
    link = dict(
      source = df['source'],
      target = df['target'],
      value = df['value'],
      color = df['color']
    ))])

fig.update_layout(title_text="Alphabet Q4 FY25 Income Statement", title_x=0.5, font_size=10, height=600)

10 Customizing Title, Size, and Axis Names

10.1 Add Title

You can add a title to your plot and center it.

Code 
fig = px.scatter(tips, x="tip", y="total_bill", title="Total Bill Title").update_layout(title_x=0.5)
fig.show()

10.2 Adjust Size

The size of the plot can be customized to fit your needs.

Code 
fig = px.scatter(tips, x="tip", y="total_bill")
fig.update_layout(
    autosize=False,
    width=200,
    height=200
)
Code 
fig.show()

10.3 Change Axis Names

You can change the labels of the x and y axes for clarity.

Code 
fig = px.scatter(tips, x="tip", y="total_bill",
                 labels={
                     "tip": "New X Label",
                     "total_bill": "New Y Label"
                 })
fig.show()

11 Applying Themes

Plotly offers several built-in themes to change the appearance of your plots.

  • ggplot2 Theme
  • Seaborn Theme
  • Plotly Dark Theme

This theme mimics the style of the popular ggplot2 library in R.

Code 
fig = px.scatter(tips, x="tip", y="total_bill", template="ggplot2")
fig.show()

This theme applies a style similar to the Seaborn library.

Code 
fig = px.scatter(tips, x="tip", y="total_bill", template="seaborn")
fig.show()

This theme uses a dark background for a modern look.

Code 
fig = px.scatter(tips, x="tip", y="total_bill", template="plotly_dark")
fig.show()

13 Animated Plot

Plotly supports animations for many chart types, though smooth transitions are best supported for scatter and bar plots. More information can be found here.

Code 
import plotly.express as px
df = px.data.gapminder()
px.scatter(df, x="gdpPercap", y="lifeExp", animation_frame="year", animation_group="country",
           size="pop", color="continent", hover_name="country",
           log_x=True, size_max=55, range_x=[100, 100000], range_y=[25, 90])

## ggplot2 Theme

This theme mimics the style of the popular `ggplot2` library in R.

```{python}
fig = px.scatter(tips, x="tip", y="total_bill", template="ggplot2")
```

# Animated Plot

Plotly supports animations for many chart types, though smooth transitions are best supported for scatter and bar plots. More information can be found [here](https://plotly.com/python/animations/).

```{python}
import plotly.express as px
df = px.data.gapminder()
px.scatter(df, x="gdpPercap", y="lifeExp", animation_frame="year", animation_group="country",
           size="pop", color="continent", hover_name="country",
           log_x=True, size_max=55, range_x=[100, 100000], range_y=[25, 90])
```
